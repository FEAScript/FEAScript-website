Tutorials

Learn by running.

These tutorials provide a step-by-step introduction to FEAScript. They show how to integrate finite element simulations into your own websites and applications, or how to run them in interactive JavaScript playgrounds such as CodePen and Scribbler. Several tutorials come in variants that solve the same physical problem in different configurations, from the basic example to more advanced setups with external meshes or multiple threads. For the equations and options behind each example, see the documentation.

New to finite elements? Start with Tri's Lab by FEAScript, where you learn the finite element method through games and block-based missions, with no code to write.
