# FEAScript-website

[![Website](https://img.shields.io/website?url=https%3A%2F%2Ffeascript.com%2F)](https://feascript.com/)

FEAScript is a finite element simulation library built in JavaScript. This is the source code of the FEAScript [website](https://feascript.com/).

## Tutorial section labels

Tutorial sections and subsections use `<div class="eyebrow label">` with a `<p>` for the title. Keep `role="heading"` and `aria-level="2"` or `aria-level="3"` to preserve heading navigation, and retain existing IDs and named anchors for section links. Level-two labels also supply the current section title in the sticky document bar.

## Tutorial figures

Schematics and meshes are black line-art SVGs in `tutorials/`, beside the tutorial pages, placed in a `<div class="center-image">` with an `image-caption`. The mesh figures of the tutorials with internally generated meshes, and the schematic of the advection-diffusion tutorial, are generated by `python3 scripts/generate-tutorial-figures.py`; rerun it when a tutorial mesh changes.

## Sitemap

`python3 scripts/update-sitemap.py` sets each `<lastmod>` in `sitemap.xml` to the date the page last changed in git (today, if it has uncommitted changes). The pre-commit hook in `.githooks/` runs it on every commit (the prepare-commit-msg hook there adds the `Signed-off-by` trailer); enable them once per clone with `git config core.hooksPath .githooks`. When you add a page that should be indexed, add its `<url>` entry by hand; pages with `noindex` stay out.
