Work with FEAScript

Simulation tools, built for your problem.

Custom engineering calculators that run in the browser, built on the open-source FEAScript library. What can be shared from each project goes back into the library and its tutorials.

Engineering calculators

A focused web application for one problem, such as a cooling fin, a wall build-up, a beam or a flow channel. Your users change the inputs you choose and see the results you choose. The finite element solve runs in their browser, so there is no simulation server to run and their data stays on their machine.

  • Delivered as plain HTML and JavaScript that you host yourself, or as a FEAScript Studio app.
  • Each calculator comes with a validation note: its results compared with an analytical solution, a published benchmark or a reference run in an open-source solver, as in the verification cases of the library.
  • A fixed price for a written scope, agreed before work starts.

Calculators cover 1D and 2D heat conduction, creeping (Stokes) flow, Euler–Bernoulli beams, front propagation and general form PDEs, on built-in meshes or meshes from Gmsh. Not sure your problem fits? Ask.

How to start

Email info@feascript.com with:

  • the problem and its physics,
  • who will use the tool, and which inputs and results they need,
  • your timeline.

You get a reply within a few working days with a scope and a fixed price, or the questions needed to get there.
