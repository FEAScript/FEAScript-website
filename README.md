# FEAScript-website

![website status](https://img.shields.io/website?url=https%3A%2F%2Ffeascript.com%2F)

FEAScript is a finite element simulation library built in JavaScript. This is the source code of the FEAScript <a href="https://feascript.com/" target="_blank">website</a>.

## Tutorial section labels

Tutorial sections and subsections use `<div class="eyebrow label">` with a `<p>` for the title. Keep `role="heading"` and `aria-level="2"` or `aria-level="3"` to preserve heading navigation, and retain existing IDs and named anchors for section links. Level-two labels also supply the current section title in the sticky document bar.

## Tutorial figures

Schematics and meshes are black line-art SVGs in `assets/`, placed in a `<div class="center-image">` with an `image-caption`. The mesh figures of the tutorials with internally generated meshes, and the schematic of the advection-diffusion tutorial, are generated by `python3 scripts/generate-tutorial-figures.py`; rerun it when a tutorial mesh changes.
